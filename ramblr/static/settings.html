Microphone

Ramblr records the mic you pick with its own stream. The system default input is never changed, so dictation keeps its mic. If the chosen mic is unplugged, Ramblr falls back to the home mic and returns by itself when it is back. Ctrl+K, "Choose microphone" does the same from any page.

Vocabulary
