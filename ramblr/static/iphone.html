Install the Ramblr Shortcut

Set it up (two minutes)

  1. Install Tailscale on the iPhone and sign in to the same tailnet, and keep it connected.
  2. Open the QR above on the iPhone and tap Install the Ramblr Shortcut, then Add Shortcut. If there is no signed file yet, build it by hand from the steps below.
  3. Action Button (iPhone 15 Pro and later): Settings → Action Button → Shortcut → Ramblr. Lock screen: long-press the lock screen → Customize → Lock Screen → add the Shortcuts control → Ramblr.
  4. Press it, talk, tap stop. It uploads over the tailnet and shows "Sent to Ramblr". The text lands on Today with a 📱 and the idea card builds about 10 minutes later.

Build it by hand

  1. Shortcuts → + → name it Ramblr.
  2. Add Record Audio (Audio Quality: Normal, Start Recording: Immediately, Finish Recording: On Tap).
  3. Add Get Contents of URL: URL , Method POST, Request Body File = Recorded Audio, Headers: Authorization = Bearer <key> and Content-Type = audio/mp4.
  4. Add Show Notification: "Sent to Ramblr".
  5. The key is RAMBLR_UPLOAD_KEY in ~/.config/ramblr/secrets.env on gus (it is never shown on this site).
